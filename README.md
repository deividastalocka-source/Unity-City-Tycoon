# Unity City Tycoon

A 2.5D city-building tycoon prototype developed in Unity using C#.

Players can design and expand their own city by placing buildings and decorations while generating income and increasing their city rating.

> **Note:** This project was developed as part of college coursework and was not developed into a fully completed game.

## Gameplay Overview

Players build and develop their city by placing structures and decorative elements. As the city grows, it generates passive income and increases its overall city rating.

The game includes:

- Building and decoration placement
- Passive income generation
- City rating progression
- City development
- Real-time UI updates

## Building and Placement System

Players can place buildings and decorative objects within the city.

Objects are instantiated dynamically using Unity and positioned within the 2.5D game environment.

This system provides the core mechanic for developing and expanding the player's city.

## Income System

The game includes a passive income system that generates money every minute.

Income scales as the city develops, allowing additional buildings and progression to increase the player's earnings.

This system demonstrates the implementation of time-based gameplay logic and progression using C#.

## City Rating System

The city rating increases as the player develops the city and places decorative elements.

The rating provides an additional measure of progression alongside the player's income and contributes to the overall development of the city.

## User Interface

The game includes a dynamic user interface displaying:

- Current money
- City rating

The interface updates during gameplay to reflect changes to the player's city and progression.
